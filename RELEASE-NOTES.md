DiceMaster v0.5.3 adds a saved Window layout selector above the tabs. Split windows remains the default. Single window puts the animated dice table and recent rolls directly below the dice selection, quantity and Roll controls in the Table tab. The participant roster is collapsible in single-window mode, and the embedded dice/history region scrolls independently. Switching layouts preserves the same room, roll history, dice skins and local table finish; it does not create a second relay connection. The separate dice window closes in single-window mode.

Recent rolls now show Time, Player, Dice and Total columns in both layouts. Time uses the relay's scheduled roll-start timestamp, converted to the viewer's local timezone and displayed as HH:mm:ss. Hover over the time for the full date and UTC offset. It is not the time the event happened to arrive during a reconnect. Completed results remain hidden until the roll animation ends.

Validation: Release build passes with zero warnings/errors against Dalamud API 15; release ZIP version verified. Both layouts share the same rendering/history method. In-game sizing, scrolling and visual confirmation are still needed. This update adds no relay requests and requires no relay deployment. The previous room-recovery relay repair remains included in the source tree. The publisher preserves the user's GitHub README and existing remembered authentication.
