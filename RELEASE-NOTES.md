DiceMaster v0.5.2 adds a local Table Style tab with Classic Felt, Midnight Velvet, Burgundy Felt, Slate, Dark Walnut and Parchment. A live preview shows the selected table with your own dice finish. The choice is saved locally and never changes another player's table or the roller's shared dice appearance.

Surface textures are subtle, deterministic drawing patterns; walnut grain and decorative inlays stay on the edges. The rolling field has no central ornament. Contrasting die edges and number outlines improve readability across light and dark finishes. These settings create no network traffic and require no texture downloads. Existing configurations default to Midnight Velvet.

Also includes the new teal-and-gold DM die installer icon, verified as a 512 x 512 PNG and inspected at 64 x 64. The GitHub README and remembered authentication are preserved.
